# UAT script for exams, transport and library (Phase 4, Sprints 15 to 19)

For the pilot school's examination cell, transport in-charge, librarian and super-users. Each
scenario names the login from `docs/demo-logins.md`, the steps and the expected result. Record
pass/fail and remarks in the last two columns. Sign-off is an input to the M4 gate.

| #   | Area           | Login                             | Steps                                                                                                           | Expected                                                                                             | Result | Remarks |
| --- | -------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------ | ------- |
| 1   | Exam setup     | `dev-coordinator`                 | **Exams → Exams**: create a periodic test for Class VI with subjects and maximum marks; open marks entry        | Exam listed; marks entry open for the class teachers                                                 |        |         |
| 2   | Marks          | `dev-teacher`                     | Teacher app **Marks**: enter marks for VI-A, one absent; submit                                                 | Totals and grades computed from the class scale; absent shown as AB                                  |        |         |
| 3   | Moderation     | `dev-coordinator`                 | Lock marks entry; reopen for one subject with a reason                                                          | Locked subjects refuse changes; the reopened one accepts; audit shows the reason                     |        |         |
| 4   | Report cards   | `dev-coordinator`                 | **Exams → Report cards**: choose the primary template, preview one pupil, release for Class IV, hide defaulters | Preview matches the layout; released cards visible to families except defaulters                     |        |         |
| 5   | Bands          | `dev-coordinator`                 | Release for VI (CCE), X (components) and XII (theory / practical)                                               | Each band renders with its layout; scaled columns and totals match the marks                         |        |         |
| 6   | Legacy match   | examination cell + platform team  | Compare one released card per band with the legacy card of the same pupil                                       | Identical marks, grades, ranks and remarks; differences listed and explained                         |        |         |
| 7   | Parent view    | `dev-parent`                      | Parent app **Results**: open the released card, download the PDF                                                | Card shows for each child; PDF downloads                                                             |        |         |
| 8   | Board results  | `dev-coordinator`                 | **Exams → Board results**: validate and commit a CBSE result file for Class X                                   | Pupils matched by board roll number, unmatched rows listed; subject analysis shown; export works     |        |         |
| 9   | Analytics      | `dev-principal`                   | **Insights → Results analytics**                                                                                | Pass % and mean per exam by class and section; weakest subjects listed                               |        |         |
| 10  | Routes         | `dev-admin`                       | **Transport → Routes and stops**: add a stop with a pickup time; assign a pupil                                 | Stop on the route; the pupil's fee profile picks the slab of the stop                                |        |         |
| 11  | Request        | `dev-parent` then `dev-admin`     | Parent app **School bus**: request a route change; admin approves in **Approvals**                              | Request on the workflow; on approval the assignment changes from the effective date; family notified |        |         |
| 12  | Live bus       | `dev-parent`                      | Parent app **School bus** with the GPS feed running                                                             | Bus position and last-seen time refresh; boarding and alighting alerts arrive                        |        |         |
| 13  | GPS feed       | platform team + vendor            | Push one NeverSkip position message with the `transport.gps` service key                                        | Position accepted and shown on **Transport → Live buses**; a wrong key is refused                    |        |         |
| 14  | Catalogue      | `dev-librarian` (or `dev-admin`)  | **Library → Catalogue**: add a title, add copies with accession numbers; upload the Excel of titles             | Copies listed by accession; upload validates and commits                                             |        |         |
| 15  | Circulation    | `dev-librarian`                   | **Library → Circulation**: issue two copies to a pupil, a third beyond the limit; return one late               | Third issue refused by the rule; the late return posts the fine per day from settings                |        |         |
| 16  | Fines          | `dev-librarian` then `dev-parent` | Collect the fine at the counter; parent app **Library**                                                         | Fine receipt in the misc ledger; the parent app shows the loan and the paid fine                     |        |         |
| 17  | Sale / digital | `dev-librarian`                   | Sell a copy with a receipt reference; add a digital item for students                                           | Copy becomes sold and immutable; the parent app lists the digital item                               |        |         |
| 18  | Stock check    | `dev-librarian`                   | **Library → Stock and sales**: open a check, scan a few accession numbers, close it                             | Missing copies listed; optional mark as lost                                                         |        |         |
| 19  | Certificates   | `dev-admin` then `dev-parent`     | **Engagement → Certificates**: issue merit certificates to VI-A; parent app **Certificates**                    | Serials per pupil, batch PDF; each family downloads its own                                          |        |         |
| 20  | Scheduled      | `dev-admin`                       | **Reports → Scheduled reports**: schedule the fee day book for Mondays 07:00 to the accountant; **Run now**     | Export queued and delivered; next run shown in IST                                                   |        |         |
