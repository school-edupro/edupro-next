# File movement (digital approval notes)

**Where:** admin portal → Approvals → File movement. Every member of staff with a login can raise a file.

## Raise a file
1. *Add new approval*: the subject, the message (headings, bold, lists, links, tables), up to 4 attachments (PDF or photo, 5 MB each).
2. Choose the **L1 approver** by name; *Add L2 approver* … up to L5. The same person cannot be at two levels, and you cannot name yourself.
3. *Submit approval*. The file gets a number (FM-YYMM-0001) and goes to L1.

## Approve
- The approver sees it under *To approve* and in the header approvals icon. Level 2 sees the file only after level 1 approves.
- **Approve** (remark optional), **Send back to the creator** (remark needed) or **Reject** (remark needed, final).
- Sent back: the creator opens the file, *Correct and submit again*; it starts again from L1 as a new round. Earlier rounds stay in the history.
- The creator can withdraw a file that is still open.

## After approval
- *Download PDF*: the note sheet with the school's name and address, the file number, the note, the attachment list and the approval trail (level, approver, decision, date and time, remark).

## Dashboard and report
- *Dashboard*: files by status, the last six months, who is holding files, the oldest open files.
- The list filters by box (To approve, My files, Decided by me, All), status, dates and search, and downloads as Excel or PDF with the school's header.
- The school admin, group admin and auditor see every file; others see the files they raised or that came to them.
