# Data inventory and DPDP classification

Purpose: the register of personal data the platform processes, its classification (logging standard section 1), lawful basis under the Digital Personal Data Protection Act 2023, retention, and the entity that data subject rights tooling (Sprint 20) operates on. New tables extend this file in the same pull request.

Data principal types: **child** (student under 18, parental consent required through the guardian), **guardian**, **employee**, **applicant** (admission), **visitor**, **vendor contact**.

## 2. Cross-cutting obligations

| Obligation                               | Implementation                                                                                                            |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Notice and consent at collection         | consent forms module (Sprint 19) and onboarding notices in the parent app; consent records keyed to purpose               |
| Verifiable parental consent for children | guardian identity verified through One Auth mobile OTP and school admission records; consent recorded per purpose         |
| Purpose limitation                       | data classes and purposes above; exports and messaging require purpose-specific permissions                               |
| Data minimisation                        | Aadhaar and religion collected only where the school's board or government scheme requires; toggled per school setting    |
| Accuracy                                 | correction workflows in student, guardian and employee modules; audit trail                                               |
| Storage limitation                       | retention schedules above executed by the retention purge job (Sprint 20) with per-school overrides within legal minimums |
| Security safeguards                      | RLS, encryption at rest for S fields (Sprint 3), TLS, MFA for privileged roles, audit                                     |
| Breach notification                      | incident runbook (Sprint 20) with the Data Protection Board timeline and affected-principal notice templates              |
| Data principal rights                    | access, correction, erasure and grievance request tooling (Sprint 20); requests logged and time-boxed                     |
| Processing by third parties              | contracts with SMS, WhatsApp, email, payment and cloud providers listed in the vendor register; data residency in India   |
| Children's data prohibitions             | no behavioural tracking or targeted advertising; analytics limited to aggregates                                          |

## 3. Legacy data to drop at migration

Plaintext passwords (`spassword`, `Password`), password reset SMS logs containing passwords, IMEI bindings (`simei`), GCM/FCM tokens (re-registered by apps), raw gateway callback logs older than 2 years, `user_master` dumps, and any `*_bk`, `*_temp`, `TempTable*` tables.
