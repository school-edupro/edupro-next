## 4. Decisions

- **Instalment = rows sharing a due date.** This makes the late fee, visibility and allocation the same for quarterly schools, monthly schools and per-student instalment variants; the anchor period (lowest sequence with that due date) carries the slab configuration.
- **Late fee is computed, not posted.** The ledger shows the amount as of a date; posting it on a receipt belongs to the collection procedure (Sprint 13), so Sprint 12 could not create a rupee the accounts team has not accepted.
- **Overrides are append-only**, like consents: a new override revokes the previous one and the audit log keeps both.
- **Marts are tables, not materialised views** (ADR-010), because materialised views cannot carry RLS policies.
- **The harness is synthetic and says so.** Its value this sprint was real: it exposed that a second setting change on the same day was ambiguous and that payment allocation left a phantom shortfall when an opening-balance credit existed; both are fixed in migration 0022.
- **`packages/ai` has no SDK dependency** and no network use in tests; the provider is chosen by environment and the mock is refused in production, following the pattern of every other development bypass in the code base.
