## 4. Decisions

- Compat writes reuse the new services rather than writing to tables directly, so the legacy app inherits scopes, the weekly-off rule and approvals; the trade-off is that a legacy call can now be refused where the old PHP accepted it, which the envelope reports as an error message.
- Lesson plan rejection returns the plan (`returned`) instead of ending it, because the legacy practice is iterative; the workflow instance history keeps every round.
- Substitution conflicts are checked against regular slots and other substitutions only; leave records do not exist yet, so the absent teacher is whoever holds the regular slot.
- Throttling is applied to alert templates only, never to approved circulars (a principal's approved message must not be dropped) and never to service messages that are one per event by construction.
- Rehearsal 2 was run as a dry run on a synthetic extract rather than skipped, so the transforms for four domains have been exercised together at volume; the report states plainly that the real dump has not been processed.
