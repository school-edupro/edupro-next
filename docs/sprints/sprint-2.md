## Decisions taken in the sprint

1. **Segregation of duties and the administrator templates.** The seeded rule says the person who grants roles must not also export the audit trail. The School Admin and Group Admin templates held both permissions, so the permission guard refused every grant made by an administrator. Migration 0009 removes `platform.audit.export` from both templates; the Auditor keeps it. Catalogue updated (`docs/design/02-rbac-permission-catalogue.md`).
2. **Teachers may delegate.** `access.delegation.create` is added to the Academic Coordinator, Class Teacher and Subject Teacher templates; the API still checks that the giver holds the role.
3. **Local storage driver tokens travel in the query string.** Fastify caps path parameters at 100 characters; the signed token is longer. Production uses S3 presigned URLs, so only the local driver is affected.
4. **`app.invite_user` returns `o_`-prefixed columns** so PL/pgSQL output names never shadow table columns (the first version failed with an ambiguous `user_id` in `ON CONFLICT`).
5. **SQL lint rule.** Any template literal that has `${}` and an upper-case SQL clause keyword is an error in `src/` of the API, workers, db and etl packages. Fixed fragments (column list constants, `whereSql` built from fixed clauses, a table name from a two-value enum) carry a `// eslint-disable-next-line no-restricted-syntax -- <reason>` on the line above the template, which reviewers treat as a checklist item. Tests are exempt.
6. **Malformed identifiers are 400, not 500.** The problem-details filter maps PostgreSQL `22P02` and `22007` to `validation-failed`.
7. **Shared HTTP setup.** `apps/api/src/app.setup.ts` configures body parsers, Helmet, CORS, rate limiting and request ids for `main.ts`, the OpenAPI export and every e2e suite, so tests exercise the production limits. The JSON parser registers through Nest's `useBodyParser` so `app.init()` does not add a second one.
