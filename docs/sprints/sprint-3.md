## Decisions taken in the sprint

1. **ADR-009** records the outbox, the SECURITY DEFINER routines for cross-tenant claiming and expiry, the adapter interface and the export pipeline.
2. **Audit staging instead of an audit outbox.** Writing the audit row in the service transaction meets "survives a crash after commit" without a second queue.
3. **A shared `@edupro/storage` package** holds the local and S3 drivers so the API and the workers write and serve the same files. A relative `STORAGE_LOCAL_DIR` resolves against the repository root.
4. **BullMQ job ids** are `outbox-<id>` (BullMQ forbids colons in custom ids).
5. **The Auditor exports the audit log, not the School Admin** (segregation of duties from Sprint 2). The Auditor template therefore gains `reports.export.create`.
6. **Playwright's Chromium** renders PDF exports; `EXPORT_PDF_ENGINE=none` disables PDF on workers without a browser (CI uses it for the smoke job).

## Services still using the post-commit audit path

Access (roles, assignments, delegations, memberships), platform (settings, years, school), files and classes set `ctx.audit` after their transaction. They are covered by the interceptor; converting them to `AuditService.stage` is a mechanical change scheduled with the Sprint 4 people modules, which are written with staging from the start.
