# Admissions: a guide for the office

## Who does what

| Person               | Does                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| Admissions clerk     | Cycles and forms, verifies applications, records interaction scores, prints offers |
| Academic coordinator | Reviews shortlisted applications (approval level 1), conducts interactions         |
| Principal            | Approves offers (level 2); draws when seats are oversubscribed                     |
| Accounts             | Confirms the admission fee (online or at the counter)                              |
| Applicants           | Apply on the public site with a mobile OTP, track status, pay, upload documents    |

## The cycle

1. **Admissions → Cycles → New**: classes, seats, dates, the form fields and documents required, the
   scoring rule (distance, sibling, staff ward, interaction), the fee.
2. Publish: the public site lists the cycle; applicants apply and receive an application number.
3. **Applications**: verify documents, add the interaction score, recompute; the dashboard shows seats
   against applications and possible duplicates (same child applying twice).
4. **Shortlist** or **Draw** when oversubscribed (the draw is recorded and repeatable).
5. **Approvals**: the coordinator and the principal approve the offer in their inbox.
6. **Offers**: the family pays the admission fee; the application becomes an admission and the pupil
   is enrolled in the section you choose, with the guardians and documents carried over.

## Five common questions

1. _An applicant lost the OTP._ They request a new code on the site; the old one expires.
2. _Two applications for the same child._ The dashboard flags them; withdraw one with a note.
3. _The score looks wrong._ Open the application, check the inputs (distance, sibling) and recompute;
   the rule of the cycle decides the points.
4. _The fee was paid but the offer still shows pending._ Check **Payments → Intents** for the
   transaction; a pending gateway callback posts the fee when it arrives.
5. _Class XI streams._ Use one cycle per stream or the stream field on the form; seats are per class.
